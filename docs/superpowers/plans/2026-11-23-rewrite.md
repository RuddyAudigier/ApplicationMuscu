# Réécriture ApplicationMuscu — Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Réécrire toute l'app (logique + front-end) en TypeScript sur la branche `rewrite`, à parité fonctionnelle avec les corrections D1–D12, sous contrôle qualité automatique.

**Architecture:** Couches `domain` (TS pur) → `data` (ports + Supabase/mock) → `features` (écrans React) ; `ui` (design system) et `platform` (Capacitor/web) transverses ; `app` assemble router et providers. L'ancien code est déplacé dans `legacy/` comme référence de parité, puis supprimé à la fin.

**Tech Stack:** React 19, Vite 8, TypeScript ~6.0, React Router 8, TanStack Query 5, Zod 4, Vitest 5 + Testing Library 16, Playwright 1.65, Supabase JS 2, Capacitor 8, CSS Modules.

**Spec:** `docs/superpowers/specs/2026-11-23-rewrite-design.md` + référence fonctionnelle `docs/rewrite/feature-inventory.md` (citée « INV §x.y »).

## Global Constraints

- Langue de l'UI : français ; `<html lang="fr">`. Tous les textes utilisateur repris mot pour mot de INV sauf décision D1–D12.
- `typescript ~6.0` (typescript-eslint exige `<6.1`), `strict: true`, `noUncheckedIndexedAccess: true`. Interdit : `any` explicite, `// @ts-ignore`.
- Aucune modification du schéma Supabase. Tables/colonnes : INV §2.1. Codes tolérés : `42P01`, `42703`, `PGRST204`, `PGRST116`.
- Règles d'import : `domain` n'importe rien hors `domain` ; `data` → `domain` ; `ui` → rien d'applicatif ; `platform` → `domain` ; `features` → tout sauf `app` et autres `features/*` internes (seulement via `features/<x>/index.ts`).
- `PR_EPSILON = 0.01`, `SHARE_ALGO_VERSION = 'PR-v10'`, variante par défaut `'Touch and Go'`, RPE entier 6–10 défaut 10.
- Dates : `IsoDate` = `YYYY-MM-DD` en **fuseau local** (D3). Jamais `toISOString().slice(0,10)` pour une date du jour.
- Aucune écriture ne supprime de performance (D1).
- Pas d'`alert`/`confirm`/`prompt` natifs (D10) : utiliser `ui/Toast` et `ui/ConfirmDialog`.
- Chaque tâche finit avec `npm run check` vert : `lint` (0 warning) + `typecheck` + `test`.
- Commits : Conventional Commits, un par tâche minimum, sur `rewrite`. Terminer par `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Ne jamais commiter `.env*` ni lire/afficher la valeur des clés.

## Review Focus

1. **Historique > 1000 performances** : PR, progression et partage doivent voir tout l'historique (D4) → test de pagination dans Task 6.
2. **Séance commencée avant minuit, terminée après** : la date de séance reste celle choisie, en local → test dans Task 4 (`todayIso` avec horloge simulée 00:30 Europe/Paris).
3. **Fermeture de l'app en pleine séance** (Android tue le WebView) : la séance en cours, bonus compris, est restaurée au relancement → test dans Task 12.
4. **Saisie à la virgule et valeurs limites** (`"62,5"`, `"0"`, `""`, `"-5"`, `"1e3"`) dans reps/poids/CSV → tests dans Task 2 (`parseWeight`, `parseReps`).
5. **Perte réseau à la fin de séance puis retour réseau** : rien de perdu, rien en double, rejeu à `online` → test dans Task 7 (file hors-ligne).
