🎯 ERGONOMIE "THUMB-FIRST"

PRINCIPES DE BASE
──────────────────────────────────────────────────────────────
1. Bottom Navigation (72px height)
   • Toujours visible et accessible au pouce
   • 5 icons + labels
   • Safe-area aware (notch, home indicator)

2. Large Touch Targets
   • Inputs: 48px minimum height
   • Buttons: 48px × 48px (padding compris)
   • Spacing: 8px grid base

3. Hiérarchie Visuelle Claire
   • Info importante (exercice actuel) : top-left eye attention
   • Inputs principaux : center-screen, large
   • Actions secondaires : small/subtle

4. Logical Grouping
   • Chaque exercice = 1 card
   • Chaque set = 1 row d'inputs
   • RPE/Notes groupées avec set

5. Zero Unnecessary Scrolling
   • 1 exercice visible à la fois (SessionRunner)
   • Inputs fit dans viewport
   • Navigation bottom pour accès rapide
